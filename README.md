### [ HA Cloud/Link SSL Exporter ](./ha_link_ssl_exporter)

![Supports aarch64 Architecture][aarch64-shield]
![Supports amd64 Architecture][amd64-shield]

Exports the SSL certificate and key used by NabuCasa HomeAssistant Link (previously Cloud) to /ssl (remote_fullchain.pem and remote_private.pem) so it can also be used for other purposes like local-network ssl or mqtt.
